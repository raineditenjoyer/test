# Galaga Redux - Космический Шутер

Классическая игра в стиле **Galaga** с современными улучшениями, созданная на **Python** с использованием **PyQt5**.

## 🎮 Особенности игры

### Геймплей
- **Классический космический шутер** в стиле Galaga
- **Система очков** с сохранением рекордов
- **Разнообразные враги** с разными паттернами движения
- **Волновая система** - сложность увеличивается
- **Красивые визуальные эффекты** - частицы, взрывы, звёзды
- **Power-ups** для улучшения оружия

### Графика
- **Векторная графика** с использованием QPainter
- **Анимированный фон** со звёздами
- **Частицы взрывов** с альфа-каналом
- **Градиентные эффекты** для космической атмосферы
- **Мигающие эффекты** неуязвимости

### Управление
- **Движение**: стрелки или WASD
- **Стрельба**: пробел
- **Пауза**: P
- **Начать игру**: Enter (в меню)
- **Новая игра**: R (после окончания)

## 🚀 Запуск игры

### Основной способ
```bash
python3 run_game.py
```

### Альтернативный способ
```bash
python3 galaga_game.py
```

### Тестирование
```bash
python3 test_game.py
```

## 🎯 Игровые механики

### Враги
- **Базовые враги** (красные) - 100 очков
- **Продвинутые враги** (фиолетовые) - 200 очков
- **Различные паттерны движения**: прямолинейное, волнообразное, диагональное

### Power-ups
- **Rapid Fire** (жёлтый) - ускоренная стрельба
- **Double Shot** (голубой) - двойная стрельба
- **Shield** (белый) - щит

### Система жизней
- **3 жизни** на начало игры
- **Неуязвимость** после получения урона
- **Визуальное мигание** при неуязвимости

## 🏆 Особенности реализации

### Архитектура
- **Объектно-ориентированный подход**
- **Паттерн MVC** (Model-View-Controller)
- **Система состояний** игры
- **Компонентная архитектура** игровых объектов

### Технологии
- **PyQt5** для GUI и рендеринга
- **QPainter** для векторной графики
- **QTimer** для игрового цикла
- **JSON** для сохранения рекордов

### Производительность
- **60 FPS** игровой цикл
- **Эффективная система коллизий**
- **Управление памятью** для частиц
- **Оптимизированный рендеринг**
