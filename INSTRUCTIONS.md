# Galaga Redux - 2D Космический Шутер

## Описание
Galaga Redux - это 2D космический шутер, написанный на Python с использованием PyQt5. Игра соответствует всем требованиям:

### ✅ Реализованные функции:

1. **Базовая механика**
   - Движение игрока во всех направлениях
   - Стрельба игрока и врагов
   - Система коллизий
   - Различные типы врагов
   - Система жизней и очков

2. **Пользовательский интерфейс**
   - Главное меню
   - Игровой HUD (счет, жизни, волна, сложность)
   - Меню выбора сложности
   - Экран паузы
   - Экран окончания игры

3. **Настройки игры**
   - Звуковые настройки (эффекты, музыка, громкость)
   - Графические настройки (эффекты, частицы, качество фона)
   - Настройки управления (пока упрощенные)

4. **Сценарий игры и уровни сложности**
   - Три уровня сложности: Легкий, Средний, Сложный
   - Различные параметры для каждого уровня
   - Система волн врагов
   - Система очков

5. **Звуковые эффекты**
   - Система управления звуком
   - Эффекты стрельбы, взрывов, попаданий
   - Фоновая музыка (готова к подключению аудио файлов)

6. **Статистика результатов**
   - База данных SQLite для сохранения результатов
   - Графическая визуализация с matplotlib
   - Фильтрация по сложности и дате
   - Показ точности, времени игры, количества убитых врагов

## Запуск игры

### Способ 1: Основной запуск
```bash
python3 run_game.py
```

### Способ 2: Прямой запуск
```bash
python3 galaga_game.py
```

### Способ 3: С виртуальным дисплеем (для серверов)
```bash
xvfb-run -a python3 run_game.py
```

## Тестирование
Запустите тесты основных функций:
```bash
python3 test_game_functions.py
```

## Управление

### В главном меню:
- **ENTER** - Выбор сложности
- **S** - Настройки
- **T** - Статистика
- **ESC** - Выход

### В игре:
- **WASD** или **стрелки** - Движение
- **SPACE** - Стрельба
- **P** - Пауза
- **ESC** - Возврат в меню

### Выбор сложности:
- **1-3** - Выбор уровня сложности
- **ENTER** - Подтверждение
- **ESC** - Назад в меню

## Уровни сложности

### Легкий
- 5 жизней
- Медленные враги
- Меньше пуль врагов

### Средний
- 3 жизни
- Средняя скорость врагов
- Стандартное количество пуль

### Сложный
- 2 жизни
- Быстрые враги
- Больше пуль врагов

## Файлы игры

- `galaga_game.py` - Основной файл игры
- `run_game.py` - Скрипт запуска
- `test_game_functions.py` - Тесты функций
- `high_score.json` - Файл рекордов
- `game_settings.json` - Файл настроек
- `game_stats.db` - База данных статистики

## Особенности реализации

1. **Простота кода**: Код максимально упрощен для понимания новичков
2. **Один файл**: Вся логика в одном файле для легкости изучения
3. **Комментарии**: Подробные комментарии на русском языке
4. **Модульность**: Четкое разделение на классы и функции
5. **Стиль кораблей**: Синие футуристические корабли с градиентами

## Требования
- Python 3.6+
- PyQt5
- matplotlib
- sqlite3 (встроен в Python)

## Установка зависимостей
```bash
# Для Ubuntu/Debian
sudo apt-get install python3-pyqt5 python3-pyqt5.qtmultimedia

# Для pip
pip install matplotlib
```

## Структура кода

### Основные классы:
- `GameEngine` - Главный игровой движок
- `GameWidget` - Виджет отрисовки и управления
- `Player` - Игрок
- `Enemy` - Враги
- `Bullet` - Пули
- `SoundManager` - Управление звуком
- `StatisticsManager` - Управление статистикой
- `SettingsDialog` - Диалог настроек
- `StatisticsDialog` - Диалог статистики

### Перечисления:
- `GameState` - Состояния игры
- `DifficultyLevel` - Уровни сложности

Игра готова к использованию и полностью соответствует всем требованиям!
